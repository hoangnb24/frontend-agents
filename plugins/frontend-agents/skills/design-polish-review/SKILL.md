# Design Polish Review

Review rendered UI quality. Use `PRODUCT.md` and `DESIGN.md` when present. Do not assume Figma is part of the workflow. Do not edit files unless explicitly assigned.

Load:

- `references/design-polish-checklist.md`
- `references/impeccable-workflow.md` when Impeccable is available or requested

Return:

- Decision: `Pass`, `Advisory`, `Fix Required`, or `Blocked`.
- Evidence: `Verified`, `Partially Verified`, or `Not Verified`.
- Severity-tagged findings with file and line references or viewport/state references.
- Required fixes.
- Residual risk.
